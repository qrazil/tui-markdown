# tui-markdown

An interactive, vim-keyed terminal markdown viewer written in
[m31](https://github.com/qrazil/m31), on the
[tui](https://github.com/qrazil/tui) widget library and the
[term-markdown](https://github.com/qrazil/term-markdown) parser.

Work in progress: this commit is the project scaffold (build script, CI,
dependency pins). See the history for the rest.
